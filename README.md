# Mise à jour

La version de NeoBase, la recherche de mises à jour (téléchargement et redémarrage en un clic) et la liste des plugins à mettre à jour.

Plugin système : il ne peut pas être désinstallé.

## Installer

Dans NeoBase : **NeoStore → À découvrir → Mise à jour → Installer**.

Développer un plugin : voir le [SDK NeoBase](https://github.com/NDesumeur/neobase-sdk).
